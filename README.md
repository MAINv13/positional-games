# Позиционные игры: Аукцион заявок при IPO

Учебный модуль по теме «Позиционные игры» для дисциплины «Теория игр»
(НИЯУ МИФИ, кафедра 22 «Кибернетика»). Лабораторная работа № 4.

Веб-приложение строит дерево последовательной игры, находит **субигровое
совершенное равновесие (SPE)** методом обратной индукции и визуализирует
равновесную траекторию. Исполняется полностью на стороне клиента, без
бэкенда.

## Возможности

- Построение дерева игры в экстенсивной форме с узлами решений и
  терминальными узлами.
- Поиск SPE методом обратной индукции — в один проход («Решить») или с
  пошаговой анимацией свёртки от листьев к корню («Пошагово»).
- Подсветка равновесного пути на дереве.
- Вывод стратегий всех игроков и сравнение равновесных выигрышей с наивной
  стратегией.
- Пять предустановленных конфигураций (см. ниже).
- Для аукциона IPO — два режима информации: полная (классический SPE) и
  приватная (байесовское равновесие с приватными оценками), а также ползунок
  дискретизации цены для перехода от дискретного набора {90, 100, 110} к
  приближению непрерывного интервала [90, 110].
- Светлая и тёмная темы (по умолчанию тёмная).
- Математическая нотация через KaTeX, графики через Plotly.js.
- Полностью русскоязычный интерфейс. Адаптивная вёрстка.

## Предустановленные игры

| Игра | Игроков | Краткое описание |
|------|---------|------------------|
| Аукцион заявок при IPO | 3 | Три фонда последовательно подают заявки на акции |
| Ультиматум-игра | 2 | Один предлагает раздел суммы, другой принимает или отклоняет |
| Сороконожка (Centipede) | 2 | На каждом ходу «взять» приз или «передать», удвоив его |
| Переговоры о разделе пирога | 2 | Раунды торга с дисконтированием выигрышей |
| Вход на рынок | 2 | Новичок решает входить ли, инкумбент — уступать или бороться |

## Запуск

Приложение использует нативные ES-модули, поэтому открывать `index.html`
двойным щелчком нельзя — нужен локальный веб-сервер.

**Через Python:**

```bash
cd positional-games
python -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере.

**Через VS Code:** установите расширение Live Server и нажмите «Go Live».

**Онлайн:** проект совместим с GitHub Pages / GitVerse Pages — достаточно
включить публикацию из корня ветки.

## Архитектура

Модуль построен по принципу разделения на независимые блоки.

**Ядро** (`core/`) не зависит от интерфейса: `GameTree` хранит дерево,
`Solver` его решает. Дерево представлено узлами двух типов — `DecisionNode`
(ход игрока) и `TerminalNode` (исход с вектором выигрышей).

**Конфигурации игр** (`games/`) — это генераторы деревьев. Каждый модуль
описывает правила конкретной игры (функцию выигрышей и построение дерева) и
схему своих параметров для интерфейса. Добавление новой игры не затрагивает
ядро и UI.

**Интерфейс** (`ui/`) отвечает за отрисовку и взаимодействие. `TreeRenderer`
рисует дерево, `Controls` генерирует элементы управления из схемы параметров,
`Results` выводит итоги.

Поиск SPE реализован как обратная индукция: алгоритм рекурсивно спускается к
листьям, затем на возврате в каждом узле решения выбирает действие,
максимизирующее выигрыш ходящего игрока, и сворачивает узел в вектор
выигрышей. Последовательность выбранных действий от корня образует
равновесный путь.
